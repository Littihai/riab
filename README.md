# riab-ui

Generate a complete color palette from a single color or an image, preview it on real screens (dashboard, landing page, forms), and copy the code into your project.

Built on top of [shadcn/ui](https://github.com/shadcn-ui/ui). Available in Thai and English.

## Development

```bash
pnpm install
pnpm --filter=v4 registry:build --style all
pnpm v4:dev
```

The site runs at http://localhost:4000.
